# 舆情分析平台

面向企业品牌与公共事件的智能舆情分析平台，支持全网多源内容监测、情感倾向识别、风险预警、传播脉络溯源与核心观点聚类，并自动生成结构化舆情研判报告与公关应对建议。

## 技术架构

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3 + Element Plus + ECharts + Vue Router + Pinia + marked |
| 后端 | Python FastAPI + SQLAlchemy |
| 数据库 | SQLite（零配置，开箱即用） |
| AI 能力 | 规则引擎（情感词典 + SimHash + 烈度打分）内置运行；预留大模型 API 接口，配置密钥后自动启用 |

## 快速开始

### 1. 启动后端（端口 8000）

```bash
cd backend
pip install -r requirements.txt
python run.py
```

首次启动会自动建库并写入演示数据（「星耀 X20 Pro 发热与续航质量争议」事件，42 条多源舆情 + 水军刷量样本）。

### 2. 启动前端（端口 5173）

```bash
cd frontend
npm install
npm run dev
```

### 3. 一键启动（Windows）

双击根目录 `start.bat`。

### 4. 访问

- 前端：<http://127.0.0.1:5173>
- 后端接口文档：<http://127.0.0.1:8000/docs>

## 功能清单（对照验收标准）

- **登录与角色**：三类角色（分析师 / 公关 / 管理员）登录认证
- **监测配置**：监测主题与关键词维护、信源通道开关、预警阈值与通知渠道配置
- **数据接入与多模态解析**：模拟多源接入（微博 / 头条 / 抖音 / 知乎 / 论坛），含图片 OCR 文本、音视频 ASR 转录文本；文本清洗 + SimHash 水军刷量去重
- **认知分析**：情感倾向（正/中/负）与细粒度情绪（愤怒/失望/恐慌/质疑）识别、S/A/B/C 四级风险评级、舆情烈度指数
- **传播溯源**：首发信源识别、引爆节点定位、关键扩散节点时间线、实体关联图谱（机构/人物/产品）
- **核心观点聚类**：按语义规则聚类观点簇并提炼公众诉求意图
- **预警告警**：高危敏感词命中、KOL 负面发声、负向声量环比激增三类规则实时告警；态势大盘支持「模拟接入新舆情」实时触发
- **处置协同**：处置状态流转（跟踪/已核实/辟谣处理/忽略/已处理）、大模型公关回应草案与应对策略生成
- **研判报告**：按事件一键生成五段式结构化报告（基本信息/传播态势/观点矩阵/风险结论/处置建议），在线预览 + Markdown / PDF 导出

## 端到端演示流程

1. 登录进入「态势大盘」：查看声量趋势、情感分布、热点词云与实时预警滚动
2. 点击「模拟接入新舆情」：实时接入一条内容并触发预警（观察指标与预警刷新）
3. 进入「研判工作台」：左侧监测流多维筛选，点击卡片查看多模态原文详情（OCR/ASR）
4. 在「事件分析与溯源」页签：查看传播时间线（首发/引爆/扩散）、观点聚类与实体图谱
5. 切到「处置协同与应对」页签：标记处置动作、点击「生成公关回应草案」查看大模型口径建议
6. 进入「报告中心」：预览已有专项报告，或点「生成报告」新建；导出 Markdown / PDF

## 启用真实大模型（可选）

默认使用规则引擎离线运行。配置环境变量后，回应草案与策略建议将调用大模型生成：

```bash
set LLM_API_KEY=sk-xxx
set LLM_BASE_URL=https://api.openai.com/v1
set LLM_MODEL=gpt-4o-mini
```

## 项目结构

```
sentiment-platform/
├── start.bat                 # 一键启动脚本
├── backend/
│   ├── requirements.txt
│   ├── run.py
│   └── app/
│       ├── main.py           # FastAPI 入口
│       ├── models.py         # 数据模型（12 张表）
│       ├── pipeline.py       # 数据接入流水线（分析→去重→预警）
│       ├── seed.py           # 演示数据集（消费电子质量争议场景）
│       ├── core/             # 分析引擎
│       │   ├── nlp.py        # 情感/情绪/烈度/风险
│       │   ├── simhash.py    # SimHash 去重
│       │   ├── clustering.py # 观点聚类
│       │   ├── graph.py      # 实体图谱/传播溯源
│       │   ├── alert.py      # 预警引擎
│       │   ├── report.py     # 报告生成
│       │   └── llm.py        # LLM 接口（预留 + 规则兜底）
│       └── routers/          # API 路由（9 个模块）
└── frontend/
    └── src/
        ├── views/            # 登录/大盘/工作台/报告/配置
        ├── layout/           # 主布局
        ├── api/ store/ router/
```
